# 🧠 Context Keeper (コンテキスト・キーパー) v0.3

長時間のAIチャット（ChatGPT / Claude / Gemini など）において、コンテキスト限界による**「過去設定の忘れ（トコロテン現象）」**や**「キャラブレ」**を防ぐためのブラウザ用ユーザースクリプトです。

現在は Tampermonkey 用のプロトタイプ（v0.3）として動作しています。

> 📌 5ちゃんねる web制作管理板『AIの「文脈忘れ」を防ぐツール開発スレ』発のOSSプロジェクトです。

---

## 💡 解決したい課題（なぜこれが必要なのか）

コンテキストが溢れてAIの記憶が飛び始める前に、ユーザーへ視覚的な警告を出し、これまでの会話の**「引き継ぎ用サマリー（セーブデータ）」をワンタッチで入力欄へ挿入**することで、新しいチャットへスムーズに記憶を引き継ぐことを目的としています。

---

## ⚙️ 現在のコア機能 (v0.3)

1. **トコロテン・メーター（暫定推計）**
   * 画面内のテキスト量を `MutationObserver`（デバウンス 800ms）で監視します。
   * ASCII文字（`0.3`）とマルチバイト文字（`1.2`）で重み付けした推定トークン数を算出し、限界値に対する使用率をゲージで視覚化します。
   * Context Keeper 自身のパネル内テキストはカウント対象から除外しています。
2. **段階的なアラート**
   * 推定値が限界値の **75%** を超えると「注意（黄）」、**90%** を超えると「危険（赤）」へと変化し、画面上で警告します。
3. **ワンタッチ・セーブ（常時表示）**
   * パネル内の「💾 引き継ぎプロンプトを挿入」ボタンを押すと、クリップボードへのコピーと同時に、AIのチャット入力欄（`contenteditable` / `textarea`）へ引き継ぎ用プロンプトを流し込みます。
   * v0.3 では `execCommand('insertText')` やペースト／入力イベントの発火・フォールバックを組み込み、エディタ側のステート更新と送信ボタン有効化を促すよう改善しています。
4. **ダークモード＆最小化UI**
   * 作業の邪魔にならないダークテーマを採用し、「－」ボタンでパネルを最小化（折りたたみ）できます。

## 🔒 安全性について（ローカル完結）

* **外部通信ゼロ・完全ローカル動作**：会話データや入力内容を外部サーバーへ送信・収集する処理は一切ありません。
* **単一ファイルの軽量コード**：ソースコードは単一ファイルで構成されており、導入前に中身を直接ご確認いただけます。

## 🚀 使い方（プロトタイプのテスト方法・約1分）

1. お使いのブラウザ（Chrome / Edge / Firefox など）に拡張機能 **[Tampermonkey](https://www.tampermonkey.net/)** をインストールします。
2. 以下のリンクをクリックするとインストール画面が開きますので、そのままインストールしてください。
   * 👉 **[Context Keeper v0.3 をワンクリックでインストール（Raw）](https://github.com/taka-keeper/context-keeper/raw/main/context-keeper.user.js)**
   * *(※手動で入れる場合は、リポジトリ内の `.user.js` ファイルを開き、右上の `[Raw]` からコードをコピーしてTampermonkeyに新規作成・保存してください)*
3. 対象のAIチャット画面（ChatGPT / Gemini / Claude）を開くと、画面右上にメーターが表示されます。

## 🆘 HELP WANTED（技術的な課題と募集事項）

オープンソースでの共同開発を歓迎しています。現在、以下の課題で詰まっており、知見をお借りしたいです！

* **【課題 #1】`contenteditable` 入力欄へのテキスト注入とステート更新（v0.3 で改善中）**
  * Gemini や Claude などの入力欄（`div[contenteditable="true"]`）に対してプログラムからテキストを流し込む際、サイトやエディタ仕様によっては送信ボタンが有効化されないケースが残る場合があります。より確実な発火方法やサイト別対応の知見を探しています。
* **【課題 #2】トークン数のより正確かつ軽量な計算**
  * 現在は文字種（ASCII / 非ASCII）の重み付けによる簡易推計を行っています。ブラウザ上で負荷なく動く高精度な計算ロジックのアイデアを求めています。
* **【課題 #3】堅牢なDOM監視とサイドバー履歴などの除外**
  * 各AIサービスのUI変更に強く、かつ Context Keeper 自身のUIやサイドバーの過去チャット履歴などを誤ってカウントしないスマートなセレクタ設計が必要です。
* **【課題 #4】Chrome拡張機能 (Manifest V3) への移行**
  * 最終的には誰でも簡単にインストールできるよう、Chrome拡張機能化を目指しています。ベースコードの移植やビルド環境の構築を手伝っていただける方を募集しています。
