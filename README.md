# 🧠 Context Keeper (コンテキスト・キーパー) v0.2

## 概要 (Overview)
長時間のAIチャット（ChatGPT, Claude, Geminiなど）において、コンテキスト限界による「過去設定の忘却（トコロテン現象）」や「キャラブレ」を防ぐためのブラウザ用ツールです。
現在はTampermonkeyのユーザースクリプトとしてプロトタイプ（v0.2）が稼働しています。

## 解決したい課題 (Why we need this)
AIとの対話が長くなると、古いコンテキストから順に押し出されて忘却されてしまいます。
このツールは、コンテキストが溢れる前にユーザーに視覚的な警告を出し、これまでの会話の「引き継ぎ用要約（セーブデータ）」をワンタッチで生成させることで、次の新しいチャットへスムーズに文脈を引き継ぐことを目的としています。

## 現在のコア機能 (v0.2 Features)
1. **トコロテン・メーター（簡易トークン推計）**: 画面内のテキスト量を `MutationObserver`（デバウンス800ms）で監視。ASCII文字（0.3）とマルチバイト文字（1.2）で重み付けした推計トークン数を算出し、限界値に対するパーセンテージをゲージで視覚化します。
2. **段階的アラート**: 推計トークン数が限界値の75%を超えると「注意（黄）」、90%を超えると「危険（赤）」へと変化し、画面上に警告を表示します。
3. **ワンタッチ・セーブ（常時表示）**: パネル内の「💾 引き継ぎプロンプトを挿入」ボタンを押すと、クリップボードへのコピーと同時に、AIのチャット入力欄へ引き継ぎ用プロンプトを直接流し込みます。
4. **ダークモード＆最小化UI**: 作業の邪魔にならないダークテーマを採用し、「－」ボタンでパネルを最小化（折りたたみ）できます。

## 🆘 HELP WANTED (技術的な課題と募集事項)
このプロジェクトはオープンソースでの共同開発を歓迎しています。現在、以下の課題で行き詰まっています。

* **【課題 #1】 `contenteditable` 入力欄へのテキスト注入とステート更新**
  * GeminiやClaudeなどの入力欄（`div[contenteditable="true"]`）に対して `innerText` 等で直接プロンプトを流し込むと、React等のフレームワーク側の内部ステートが更新されず、送信ボタンが有効化されないケースがあります。これを確実に突破するハックを探しています。
* **【課題 #2】 トークン数のより正確かつ軽量な計算**
  * 現在は文字種別（ASCII / 非ASCII）の重み付けによる簡易推計を行っています。各AIモデルのトークン計算を、ブラウザ上で重くならずに精度良く行う方法（または軽量ライブラリ）を探しています。
* **【課題 #3】 堅牢なDOM監視と自身UIの除外**
  * 各AIサービスのUI変更に強く、かつContext-Keeper自身のUIテキストやサイドバーの履歴テキストを誤ってカウントしないスマートなセレクタ設計が必要です。
* **【課題 #4】 Chrome拡張機能 (Manifest V3) への移行**
  * 最終的には誰でも簡単にインストールできるよう、Chrome拡張機能化を目指しています。ベースコードの移植やビルド環境の構築を手伝ってくれる方を募集しています。

## 使い方 (プロトタイプのテスト方法)
1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) をインストールします。
2. 本リポジトリの [`context-keeper.user.js`](./context-keeper.user.js) を開き、右上の **`[Raw]`** ボタンを押してインストールします（または中身を新規スクリプトとしてコピペ・保存します）。
3. 対象のAIチャット画面（ChatGPT / Gemini / Claude）を開くと、画面右上にメーターが表示されます。
