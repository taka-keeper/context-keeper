# 🧠 Context Keeper (コンテキスト・キーパー)

## 概要 (Overview)
長時間のAIチャット（ChatGPT, Claude, Geminiなど）において、コンテキスト限界による「過去設定の忘却（トコロテン現象）」や「キャラブレ」を未然に防ぐためのブラウザ用ツールです。
現在はTampermonkeyのユーザースクリプトとしてプロトタイプが稼働しています。

## 解決したい課題 (Why we need this)
AIとの対話が長引くと、古いコンテキストから順に押し出されて消えてしまいます。
本ツールは、コンテキストが溢れる前にユーザーに警告を出し、これまでの会話の「要約（セーブデータ）」を生成させることで、次回のチャットへ文脈を引き継ぐことを目的としています。

## 現在のコア機能 (MVP Features)
1. **トコロテン・メーター**: 画面内のテキスト量を監視し、推計限界値に対するパーセンテージをゲージで視覚化。
2. **限界アラート**: 限界値の80%を超えると、画面上に警告を表示。
3. **ワンタッチ・セーブ**: 警告時にボタンが表示され、クリックすると「ここまでの設定を要約するプロンプト」をクリップボードにコピー。

## 🆘 HELP WANTED (技術的な課題と募集事項)
本プロジェクトはオープンソースでの共同開発を歓迎しています。現在、以下の課題で行き詰まっています。

- **[Issue #1] トークン数の正確かつ軽量な計算**
  - 現在はDOMから抽出した純粋な「文字数」をベースに推計しています。各AIモデルの正確なトークン計算を、ブラウザ上で軽量に行う方法（または適したライブラリ）を探しています。
- **[Issue #2] 堅牢なDOM監視**
  - AIサービスのUI変更（クラス名の変更など）に強く依存しています。MutationObserverを用いた、より壊れにくいテキスト取得のロジックが必要です。
- **[Issue #3] Chrome拡張機能 (Manifest V3) への移行**
  - 最終的には誰でも簡単にインストールできるよう、Chrome拡張機能化を目指しています。ベースコードの移植やビルド環境の構築を手伝ってくださる方を募集しています。

## 使い方 (How to test prototype)
1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) をインストール。
2. 本リポジトリの `context-keeper.user.js` の中身を新規スクリプトとして追加・保存。
3. 対象のAIチャット画面を開くと、右上にメーターが表示されます。
