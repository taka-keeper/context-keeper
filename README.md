# 🧠 Context-Keeper (v0.31)

AIチャット（Gemini / ChatGPT / Claude）の会話が長くなった際に発生する**「文脈忘却（トコロテン現象）」**を防ぐための、ブラウザ用ユーザースクリプト（Tampermonkey）です。

画面右上にトークン消費量の推計メーターを常時表示し、限界に近づくとアラートでお知らせ。ワンクリックで「引き継ぎ用の要約プロンプト」を入力欄へ自動セット＆クリップボードにコピーできます。

---

## ✨ 主な機能 (v0.31)

* **マルチAI対応**: `Gemini` / `ChatGPT` / `Claude` の3大チャットサービスに対応。
* **リアルタイム・トークン推計メーター**:
  * 英数字・記号（ASCII）を約 `0.3` トークン、日本語などのマルチバイト文字を約 `1.2` トークンとして概算。
  * `MutationObserver`（0.8秒デバウンス）により、ブラウザの動作を重くせず自動更新。
* **3段階の視覚アラート**:
  * 🟢 **安全**: 0% 〜 74%
  * 🟡 **注意**: 75% 〜 89%（枠線とバーが黄色に変化＋警告メッセージ表示）
  * 🔴 **危険**: 90% 〜 100%（枠線とバーが赤色に変化）
* **確実な引き継ぎプロンプト自動挿入（v0.31強化）**:
  * ボタンを押すと、引き継ぎ用の要約指示プロンプトをクリップボードにコピーしつつ、チャット入力欄へ自動入力。
  * **React / ProseMirror / Quill 対応**: `textarea` のネイティブセッター呼び出しや、`contenteditable` 向けの3段階フォールバック（`execCommand` → 擬似ペーストイベント → 直接書き換え＋`InputEvent`）により、各AIサービスの送信ボタンが確実に有効化されます。
* **ダークテーマ＆最小化UI**: 作業の邪魔にならない半透明ダークデザイン。ヘッダーの `－` / `＋` ボタンで折りたたみ可能。

## 📦 インストール方法

1. ブラウザに拡張機能 **[Tampermonkey](https://www.tampermonkey.net/)** をインストールします（Chrome / Edge / Firefox 等）。
2. Tampermonkeyのアイコンをクリックし、「新規スクリプトを作成」を選択します。
3. エディタ内の既存コードをすべて消し、本リポジトリのスクリプトを貼り付けて保存（`Ctrl + S`）します。
4. Gemini / ChatGPT / Claude のページを開くと、画面右上にパネルが表示されます。

## ⚙️ カスタマイズ

スクリプト冒頭の設定値を書き換えることで、環境に合わせて調整できます。

```javascript
const LIMIT_TOKENS = 15000;      // 上限トークン数（現在はテスト用に低めの15,000に設定中）
const WARNING_THRESHOLD = 0.75;  // 注意（黄）になる割合
const DANGER_THRESHOLD = 0.90;   // 危険（赤）になる割合
const SAVE_PROMPT = "...";       // 引き継ぎ時に自動挿入されるプロンプト文
